TREASURE QUEST: STARLIGHT TEMPLE

This version includes 30 playable level entries on the scrolling magical path.
The original temple background and original first three maze layouts are preserved.
Levels 4-30 use the same maze mechanics with additional coins and traps, and
increasing coin rewards. Completing a level and claiming its chest unlocks the
next level. Completing Level 10 unlocks Luna the Star Mage.

Run from this folder with:
    python main.py

Required packages:
    pip install pillow

Controls: Arrow keys or WASD.
